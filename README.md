Repository ini berisi dokumentasi simulasi topologi jaringan (PNET LAB dan EVE-NG) konfigurasi MikroTik RouterOS/Cisco, virtualisasi Proxmox VE, dan monitoring stack (Zabbix/Grafana).
1. [Project 1: Basic Campus Network & VLAN Segmentation](./project-1-basic-vlan)
   - *Key Features:* VLAN 802.1Q, Inter-VLAN Routing, DHCP Server, Spanning Tree Protocol (STP).
2. [Project 2: Enterprise Redundant Core & OSPF Dynamic Routing](./project-2-ospf-redundancy)
   - *Key Features:* Single-area OSPF, LACP Link Aggregation, Failover Testing.
3. [Project 3: Multi-WAN PCC Load Balancing & Mangle Traffic Steering](./project-3-multiwan-mangle)
   - *Key Features:* MikroTik Mangle, PCC Load Balancing, Policy-Based Routing, Recursive Failover.
4. [Project 4: Proxmox Homelab & Automated Monitoring Stack](./project-4-proxmox-monitoring)
   - *Key Features:* Proxmox VE, Docker, Zabbix/Grafana SNMP Monitoring, AdGuard Home, Tailscale.
